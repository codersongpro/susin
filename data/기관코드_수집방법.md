# 기관코드 사전 (org_codes.json)

에듀파인 개인수신그룹 일괄등록 양식의 E열 `수신기관코드` 는 행정표준코드도
나이스 표준학교코드도 아닌 **에듀파인 내부 대내조직 코드**다. 형식은 영문자 1글자 +
숫자 9자리이고, 충북은 `M10` 으로 시작한다 (나이스 충북 시도교육청코드와 같은 계보).

공개 데이터로는 구할 수 없으므로 **에듀파인에서 직접 수확한다.**

## 수확 방법

1. 에듀파인 `개인설정 > 개인수신그룹관리` 로 간다
2. 수신그룹을 하나 만들고, 조직도에서 필요한 기관을 선택해 저장한다
   (상위 체크박스를 켜면 하위 기관이 한꺼번에 잡히는지 먼저 확인해 볼 것)
3. 같은 화면의 `파일양식받기` 를 누르면 방금 등록한 내용이 코드와 함께 내려온다
4. 신통픽 `에듀파인` 탭 → `기관코드 가져오기` 에서 그 파일을 고른다

한 번 수확해 두면 계속 쓰인다. 학교 신설·통폐합이 있으면 같은 방법으로 다시 받아
합치면 되고, 기존 항목은 덮어쓰기 전에 무엇이 바뀌는지 먼저 보여준다.

## 저장 형태

`기관` 은 `{에듀파인 수신기관명(전체경로): 기관코드}` 다. 짧은 이름을 키로 쓰지 않는
이유는 `행정지원과` 처럼 여러 기관에 같은 부서명이 있기 때문이다. 짧은 이름으로
찾았을 때 후보가 둘 이상이면 아무것도 고르지 않고 후보를 보여준다.
