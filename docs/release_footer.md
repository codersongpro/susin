## 받는 방법

**`sintongpick.exe` 를 받아 바로 실행하세요.** 설치는 필요 없습니다.

백신 때문에 EXE 를 받기 어려우면 `sintongpick-windows.zip` 을 받으세요.

## 백신이 막는다면

이 프로그램은 마우스와 키보드를 대신 움직입니다. 백신은 이 동작을 키로거나 원격제어
프로그램과 구분하지 못합니다. 코드 서명 인증서가 없고 파일이 새것이라 평판도 쌓이지
않았습니다.

- EXE 다운로드 자체가 차단되면 정보보안 담당자에게 확인한 뒤 ZIP 을 쓰세요.
- 파란 경고창이 뜨면 [추가 정보] 를 누르고 [실행] 을 누릅니다.
- **업무망 PC 라면 백신 예외를 직접 등록하지 마시고 정보보안 담당자와 상의하세요.**

소스와 빌드 기록이 모두 공개돼 있으니 출처를 설명할 때 쓰시면 됩니다.
