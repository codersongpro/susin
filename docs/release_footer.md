## 받는 방법

**`sintongpick.exe`를 받아 바로 실행하세요.** 설치는 필요 없습니다.

백신 정책 때문에 EXE를 직접 받기 어려운 환경을 위해 `sintongpick-windows.zip`도 함께 제공합니다.

## 백신이 막는다면

이 프로그램은 마우스와 키보드를 대신 움직입니다. 그게 하는 일인데, 백신 입장에서는
키로거나 원격제어 프로그램과 구분이 되지 않습니다. 코드 서명 인증서가 없고 파일이
새것이라 평판도 쌓이지 않았습니다.

- EXE 다운로드 자체가 차단되면 정보보안 담당자에게 확인한 뒤 ZIP 자산을 사용하세요.
- 파란 경고창이 뜨면 `추가 정보` → `실행` 입니다.
- **업무망 PC 에서는 백신 예외를 직접 등록하지 마시고 정보보안 담당자와 상의하세요.**

소스와 빌드 기록이 모두 공개돼 있으니 출처를 설명하실 때 쓰시면 됩니다.
