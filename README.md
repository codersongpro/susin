# 신통픽

**수**신픽 + 소**통**픽. 충북 교사가 수신자를 고르는 두 가지 일을 한 앱에서 합니다.

| 도구 | 어디에 | 하는 일 |
|---|---|---|
| **수신픽** | 에듀파인 | 개인수신그룹 일괄등록 엑셀을 만들어 줍니다 |
| **소통픽** | 소통메신저 | [사용자 선택] 창에서 검색하고 결과를 눌러 담는 일을 대신 반복합니다 |

명단을 넣어 충북 기관명으로 정리하는 부분은 둘이 같고, 그 뒤부터 갈립니다.
앱을 켜면 맨 위에서 쓸 도구를 고르고, 고른 도구에 필요한 화면만 남습니다.

Windows 전용이고 설치가 필요 없습니다. [소통픽](https://github.com/codersongpro/sotong)에서 이어졌습니다.

## 받기

[Releases](https://github.com/codersongpro/susin/releases/latest) 에서 둘 중 하나를 받습니다.

| 파일 | 설명 |
|---|---|
| `sintongpick-windows.zip` | **권장.** 압축을 풀고 안의 exe 를 실행합니다. 백신 오탐이 훨씬 적습니다 |
| `sintongpick.exe` | 파일 하나라 간편하지만 백신이 막을 수 있습니다 |

### 백신이 막는다면

이 프로그램은 마우스와 키보드를 대신 움직입니다. 백신은 이 동작을 키로거나 원격제어
악성코드와 구분하지 못합니다. 코드 서명이 없고 파일이 새것이라 평판도 없어서 오탐이 자주
납니다. 특히 `--onefile` exe 는 실행할 때 자기 안의 압축을 임시 폴더에 풀어 쓰는데,
이 구조가 드로퍼 악성코드와 같습니다.

그래서 `.zip`(onedir) 도 함께 올립니다. 압축을 스스로 푸는 단계가 없어 대부분 통과합니다.

막혔을 때는 이 순서로 해 보세요.

1. `.zip` 을 먼저 써 봅니다
2. Windows 보안의 보호 기록에서 탐지 이름을 확인합니다.
   `Wacatac`, `Bearfoos` 같은 일반 이름이면 휴리스틱 오탐입니다
3. [VirusTotal](https://www.virustotal.com) 에 올려 어느 엔진이 무엇으로 잡는지 봅니다
4. [Microsoft 오탐 신고](https://www.microsoft.com/en-us/wdsi/filesubmission) 에 제출합니다.
   무료이고 보통 1~3일 안에 풀립니다

**업무망 PC 라면 임의로 백신 예외를 등록하지 마시고 정보보안 담당자와 상의하세요.**

근본 해결은 코드 서명 인증서(연 20~40만 원)인데 아직 없습니다.
파이썬이 있거나 설치해도 되는 PC 라면 `시작.bat` 으로 소스에서 바로 실행할 수 있고,
이 경우에는 exe 가 아니라서 백신 문제가 생기지 않습니다.

## 수신픽: 에듀파인 수신그룹

공문 기안에서 수신 기관이 30곳이면 조직도에서 검색하고, 체크하고, `>>` 를 누르는 일을
30번 되풀이해야 합니다. 클릭 120번입니다. 같은 이름의 기관을 잘못 고르면 공문이 엉뚱한
곳으로 갑니다.

에듀파인에는 `개인설정 > 개인수신그룹관리 > 일괄등록` 이 있습니다. 엑셀 한 장을 올리면
수신그룹이 만들어지고, 다음부터는 `수신자 지정 > 개인수신그룹` 에서 그룹 하나만 고르면
됩니다. 클릭 120번이 2번으로 줄어듭니다. 신통픽이 그 엑셀을 만들어 줍니다.

## 쓰는 순서

### 1. 내 정보 (처음 한 번)

[수신그룹 엑셀] 화면에 `사용자ID` 와 `사용자명` 을 적습니다. 등록교육청은
**충청북도교육청** 으로 자동 적용됩니다. 한 번 저장한 값은 다음 실행에도 남아 있습니다.

### 2. 명단 넣고 엑셀 만들기

[명단 입력] 화면에서 **수신픽** 을 고르고 기관 명단을 붙여넣습니다.
줄바꿈, 쉼표, 탭 어느 것으로 나눠도 되고, 글머리기호와 번호는 알아서 떼어 냅니다.

```
학성초
한천초, 백곡초
1. 충북외고
충청북도진천교육지원청 학성초등학교
```

### 부서에 보내려면

교육청, 교육지원청, 직속기관의 **부서** 도 수신자가 됩니다. 학교와 달리 이름 하나로는
기관이 정해지지 않을 때가 있습니다.

| 입력 | 결과 |
|---|---|
| `정책기획과` | 한 곳뿐이라 바로 확정됩니다 |
| `행정과` | **11곳에 있어서 확정하지 않습니다.** 후보를 보여 주고 고르게 합니다 |
| `청주교육지원청 행정과` | 상위조직과 맞물려 한 곳으로 좁혀집니다 |
| `단재교육연수원 교육연수부` | 3단계도 됩니다 |
| `충청북도청주교육지원청 행정과` | 전체경로로 적어도 됩니다 |

전체경로를 외울 필요는 없습니다. [기관 찾아보기] 를 누르면 770곳 가운데서 검색해 고를 수
있습니다. 찾을 말을 띄어 적으면 그 말이 모두 들어간 기관만 남습니다.
(예: `청주 초등학교`, `행정과`, `단재 연수부`)

부서는 엑셀로 올리세요. 좌표 자동선택은 조직명 칸에 `행정과` 를 쳐서 첫 결과를 고르는
방식이라, 여러 곳에 겹치는 부서명에서는 엉뚱한 곳이 잡힐 수 있습니다.

### 결과 확인

[명단 추출] 을 누르면 기관이 네 가지로 나뉩니다.

- **확정**: 정식명, 별칭, 전체경로가 정확히 맞은 기관
- **같은 이름이 여럿**: `행정과` 처럼 실제로 여러 곳에 있는 기관. 더블클릭해서 고릅니다
- **추정**: 편집거리로 짐작만 한 기관. 이것도 더블클릭해서 고릅니다
- **찾지 못함**: 사전에 없는 기관

**추정 상태에서는 엑셀에 들어가지 않습니다.** 엑셀은 그대로 등록되기 때문에, 틀린 기관이
조용히 들어가는 것을 막는 가장 중요한 규칙입니다.

[수신그룹 엑셀] 화면에서 그룹명을 적고 [수신그룹 엑셀 만들기] 를 누릅니다. 그룹명은
에듀파인에서 나중에 찾기 쉽게 대상과 시기를 함께 적으세요. (예: `2026 진천 초등학교`,
`2학기 업무담당자`) 그룹기호는 비워 둬도 됩니다. 코드가 없는 기관은 목록으로 보여 주므로
조용히 빠지는 기관은 없습니다.

### 3. 코드가 없는 기관

[코드 없는 기관 순차 복사] 를 씁니다. 기관명을 한 건씩 클립보드에 넣어 주므로, 조직명 칸에
`Ctrl+V` 를 누르고 Enter, 체크, `>>` 만 되풀이하면 됩니다. 다음 기관으로는 Enter 키로
넘어갑니다.

수신픽에는 위치 설정이 없습니다. 엑셀로 올리는 방식이라 마우스 위치를 캡처할 일이 없습니다.
소통픽에서 캡처해 둔 위치는 그대로 남아 있습니다.

## 안전장치

공문이 엉뚱한 기관으로 가지 않도록 둔 규칙입니다.

- **추정은 자동으로 확정하지 않습니다.** 정확 일치, 약칭, 접두어까지만 자동이고,
  편집거리로 찾은 것은 사람이 골라야 합니다.
- **같은 이름이 여럿이면 아무것도 고르지 않습니다.** `행정과` 는 11곳에 있습니다.
  짧은 이름으로 후보가 둘 이상이면 후보만 보여 줍니다. 전체경로
  (`충청북도충주교육지원청 행정과`)로 적으면 정확히 찾습니다.
- **비슷한 지역명을 편집거리로 붙이지 않습니다.** 청주와 충주는 한 글자 차이입니다.
  기관을 찾는 경로에서는 퍼지 매칭을 모두 뺐습니다. `청주교육지원청 행정과` 가 충주로
  가면 안 되기 때문입니다.
- **빠지는 것은 반드시 알립니다.** 코드가 없거나 이름이 정해지지 않은 기관은 사유와 함께
  목록으로 나옵니다.
- **학교급을 넘지 않습니다.** `오송솔미초` 가 `오송솔미초병설유치원` 으로 붙지 않습니다.

### 파일 하나만 받아서 쓰기 (Git 없이)

**[개발용 실행.bat 받기](https://github.com/codersongpro/susin/raw/main/%EA%B0%9C%EB%B0%9C%EC%9A%A9%20%EC%8B%A4%ED%96%89.bat)**

링크를 눌렀는데 글자만 보이면 그 화면에서 `Ctrl+S` 로 저장하세요. 또는
[파일 화면](https://github.com/codersongpro/susin/blob/main/%EA%B0%9C%EB%B0%9C%EC%9A%A9%20%EC%8B%A4%ED%96%89.bat)
오른쪽 위의 다운로드 단추(Download raw file)를 누릅니다.

받은 파일은 아무 곳에나 두고 실행합니다. 옆에 신통픽 코드가 없으면 GitHub 에서 최신 코드를
받아 `%USERPROFILE%\sintongpick-dev` 에 풀고 거기서 앱을 띄웁니다. 누를 때마다 새로
받으므로 늘 최신입니다. 설정은 다른 곳에 저장되어 지워지지 않습니다.

인터넷에서 받은 파일이라 윈도우가 "PC 보호" 창을 띄우면 [추가 정보] 를 누르고 [실행] 을
누릅니다. 업무망 PC 라면 임의로 실행하지 말고 정보보안 담당자와 상의하세요.
파이썬이 없으면 `sintongpick-dev` 폴더의 `시작.bat` 을 한 번 실행해 파이썬을 깝니다.

깔 패키지는 함께 받은 코드의 `requirements.txt` 를 `tools/ensure_packages.py` 가 읽어
정합니다. 패키지가 늘어도 bat 를 새로 받을 필요가 없습니다.

### 저장소를 받아서 쓰기 (Git 있을 때)

```
git clone https://github.com/codersongpro/susin.git
cd susin
```

그다음부터는 **`개발용 실행.bat`** 만 누르면 됩니다. `git pull` 로 최신 코드를 받고,
빠진 패키지만 깔고, 앱을 띄웁니다. 파이썬이 없으면 `시작.bat` 을 한 번 실행해 파이썬을
깐 뒤에 쓰세요.

릴리즈는 고치고 확인까지 마친 뒤에 한 번만 합니다. exe 만 확인하고 싶으면 Actions 에서
`version` 을 비우고 돌립니다. 릴리즈는 만들어지지 않고 exe 만 artifact 로 남습니다.

## 개발

```bash
pip install -r requirements.txt
python3 -m unittest discover -s tests
python main.py
```

빌드는 `build.bat` (PyInstaller, 산출물 `dist/sintongpick.exe`)입니다.
CI 는 onefile exe 와 onedir zip 을 모두 만들고, `tools/make_version_file.py` 로 제품명,
회사명, 버전을 exe 에 넣습니다. 비어 있으면 백신 의심 점수가 올라갑니다.

글꼴은 `assets/fonts/` 의 Pretendard 입니다. 앱이 이 파일을 프로세스 전용으로 올려 쓰고
(Windows), 올리지 못하면 맑은 고딕을 씁니다.

### 릴리즈

**`CHANGELOG.md` 를 먼저 갱신합니다.** 거기 적은 내용이 그대로 Release 본문이 됩니다.

```bash
# 1. CHANGELOG.md 맨 위에 '## vX.Y.Z' 단락을 쓴다
# 2. 버전을 한꺼번에 맞춘다 (main.py, index.html)
python3 tools/bump_version.py 2.1.1
# 3. 테스트
python3 -m unittest discover -s tests
# 4. 커밋하고 작업 브랜치와 main 둘 다 push
```

그다음 둘 중 하나로 릴리즈합니다.

- **Actions 탭** 의 `릴리즈 빌드` 에서 Run workflow 를 누르고 `version` 에 `v2.1.1` 을
  적습니다. 러너가 태그까지 만들어 주므로 태그를 밀 권한이 없어도 됩니다.
- **태그를 밉니다.** `git tag -a v2.1.1 -m "..." && git push origin v2.1.1`

릴리즈 본문은 `CHANGELOG.md` 의 해당 단락에 `docs/release_footer.md`(받는 방법, 백신
안내)를 붙여 만듭니다 (`tools/make_release_notes.py`). 고정 안내문은 워크플로가 아니라
`docs/release_footer.md` 에서 고칩니다.

버전이 어긋나면 테스트가 잡습니다. 랜딩페이지 표기, `APP_VERSION`, `CHANGELOG` 단락이
모두 같아야 통과합니다.

### 랜딩페이지 배포 (Vercel)

`index.html`, `terms.html`, `license.html` 세 장과 사용 방법 영상(`assets/video/`)입니다. 인라인 CSS 와 외부 링크만 쓰므로 영상 말고는 다른 파일이 필요 없습니다. 뒤의 두 장은 `tools/build_notices.py` 가 만듭니다.

**Git 연동 (권장)**: [vercel.com/new](https://vercel.com/new) 에서 이 저장소를 고르고
Framework Preset 을 `Other`, Build Command 를 비워 두면 끝납니다. 이후 `main` 에 push 할
때마다 자동으로 배포되고, 토큰이나 시크릿은 필요 없습니다.

**CLI**

```bash
npm i -g vercel
vercel          # 미리보기
vercel --prod   # 운영 배포
```

`.vercelignore` 가 HTML 세 장, 영상 폴더, `vercel.json` 만 남기고 나머지를 제외합니다.
빼지 않으면 `outputDirectory` 가 저장소 루트라 앱 소스와 `data/` 의 4MB CSV 까지
공개 URL 로 나갑니다.

`vercel.json` 에 짧은 주소 두 개를 걸어 두었습니다.

| 주소 | 가는 곳 |
|---|---|
| `/download` | 최신 릴리즈 |
| `/github` | 저장소 |

배포한 랜딩페이지 주소를 동료에게 알려 주면 거기서 바로 받을 수 있습니다.

GUI 없이도 핵심 로직은 모두 테스트합니다. 파싱, 매칭 등급, 코드 조회, 엑셀 생성,
붙여넣기부터 엑셀까지의 전체 경로입니다.

## 라이선스

신통픽은 **무료로 쓸 수 있고, 판매와 수정은 허락 없이 할 수 없습니다.** 원본 그대로 무료로
나눠 주는 것은 됩니다. 조건 전문은 [LICENSE](LICENSE)(신통픽 사용 허가서)에 있고,
소스 코드는 내용을 확인하라고 공개한 것입니다. 이용 조건은 랜딩페이지의 이용약관과
라이선스 페이지(`terms.html`, `license.html`)에 있습니다.

함께 묶인 소프트웨어와 글꼴은 사용 허가서가 아니라 각자의 라이선스를 따릅니다. 저작권 표시와
전문은 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)와 `licenses/` 폴더에 있고, 실행 파일과
zip 에도 같은 파일이 들어갑니다.

PyAutoGUI 를 설치하면 GPL-3.0 인 MouseInfo 가 함께 깔리지만, 신통픽은 쓰지 않으므로 실행 파일에서
뺍니다(`sintongpick.spec` 의 `excludes`). 릴리즈 빌드는 exe 에 MouseInfo 가 남아 있으면 멈춥니다.

사용하는 라이브러리를 바꾸면 `tools/build_notices.py` 의 목록을 고치고 `--apply` 로 돌립니다.
고지문과 약관, 라이선스 페이지가 한꺼번에 다시 만들어지고, 어긋나면 테스트가 잡습니다.
