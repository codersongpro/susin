# 신통픽

**수**신픽 + 소**통**픽. 충북 교사가 수신자를 고르는 두 가지 일을 한 앱에서 한다.

| 도구 | 어디에 | 하는 일 |
|---|---|---|
| **소통픽** | 소통메신저 | [사용자 선택] 창에서 검색 → 결과 클릭 → 선택을 자동 반복 |
| **수신픽** | 에듀파인 | 개인수신그룹 일괄등록 엑셀을 만들어 올린다 |

명단을 넣어 충북 기관명으로 정리하는 부분은 둘이 같다. 그 다음부터 갈린다.
앱을 켜면 맨 위에서 어느 쪽을 쓸지 고르고, 고른 쪽에 필요한 탭만 남는다.

Windows 전용 · 무설치 · [소통픽](https://github.com/codersongpro/sotong)에서 이어졌다.

## 받기

[Releases](https://github.com/codersongpro/susin/releases/latest) 에서 둘 중 하나를 받는다.

| 파일 | 설명 |
|---|---|
| `sintongpick-windows.zip` | **권장.** 압축을 풀고 안의 exe 실행. 백신 오탐이 훨씬 적다 |
| `sintongpick.exe` | 파일 하나로 간편하지만 백신이 막을 수 있다 |

### 백신이 막는다면

이 프로그램은 **마우스와 키보드를 자동으로 움직인다.** 그게 하는 일이다. 그런데 그 동작은
키로거·원격제어 악성코드의 행위 특징과 구분되지 않는다. 여기에 코드 서명이 없고 파일이
새것이라 평판도 없으니, 백신이 자주 오탐한다. 특히 `--onefile` exe 는 실행할 때 자기 안의
압축을 임시 폴더에 풀어 실행하는데, 그 구조가 드로퍼 악성코드와 같다.

그래서 `.zip`(onedir) 을 함께 배포한다. 자기압축 해제 단계가 없어 대부분 통과한다.

막혔을 때 순서:

1. `.zip` 쪽을 먼저 써 본다
2. `Windows 보안 → 보호 기록` 에서 탐지 이름을 확인한다.
   `Wacatac`, `Bearfoos` 같은 generic 이름이면 전형적인 휴리스틱 오탐이다
3. [VirusTotal](https://www.virustotal.com) 에 올려 몇 개 엔진이 무엇으로 잡는지 본다
4. [Microsoft 오탐 신고](https://www.microsoft.com/en-us/wdsi/filesubmission) 에 제출한다.
   무료이고 보통 1~3일 안에 풀린다

**업무망 PC 에서는 임의로 백신 예외를 등록하지 말고 정보보안 담당자와 상의한다.**

근본 해결은 코드 서명 인증서다 (연 20~40만 원). 아직 없다.

파이썬이 있거나 설치해도 되는 환경이면 `시작.bat` 으로 소스에서 바로 실행할 수 있다.
exe 가 아니라서 이 문제 자체가 없다.

## 수신픽 — 에듀파인 수신그룹이 왜 필요한가

공문 기안에서 수신 기관이 30곳이면 조직도에서 검색 → 체크 → `>>` 를 30번 반복해야 한다.
클릭 120번이다. 동명 기관을 잘못 고르면 공문이 엉뚱한 곳으로 간다.

에듀파인에는 `개인설정 > 개인수신그룹관리 > 일괄등록` 이 있다. 엑셀 한 장을 올리면
수신그룹이 통째로 만들어지고, **다음부터는 `수신자 지정 > 개인수신그룹` 에서 그룹 하나만
고르면 끝난다.** 클릭 120번이 2번이 된다.

신통픽은 그 엑셀을 만들어 준다.

## 쓰는 순서

### 1. 기관코드 가져오기 (처음 한 번)

일괄등록 양식의 `수신기관코드` 는 행정표준코드도 나이스 학교코드도 아닌 **에듀파인 내부
코드**다 (영문자 1 + 숫자 9, 충북은 `M10`으로 시작). 공개 데이터로는 구할 수 없어서
에듀파인에서 직접 가져온다.

1. `개인설정 > 개인수신그룹관리` 에서 그룹을 하나 만들고, 조직도에서 기관을 선택해 저장
2. 같은 화면의 `파일양식받기` — 방금 등록한 내용이 **코드와 함께** 내려온다
3. 신통픽 `4. 수신그룹 엑셀` 탭 → `기관코드 가져오기…` 에서 그 파일 선택

조직도 상위 노드를 통째로 선택하면 한 번에 수백 곳을 가져올 수 있다.
저장소에는 이미 충북 **770곳**이 들어 있다 (`org_codes.json`).

### 2. 내 정보 (처음 한 번)

`등록교육청코드` · `사용자ID` · `사용자명`. 가져오기 파일에서 자동으로 채워지지만,
**이미 채워 둔 값은 덮어쓰지 않는다** — 조직도를 통째로 내보낸 파일에는 본인 것이 아닌
등록교육청코드가 들어 있을 수 있기 때문이다.

`등록교육청코드`는 본인이 속한 교육지원청 코드다 (예: 진천 `M100000098`).

### 3. 명단 넣고 엑셀 만들기

`1. 명단 입력` 탭에서 **수신픽**을 고르고 기관 명단을 붙여넣는다.
줄바꿈·쉼표·탭 아무거나 되고, 글머리기호와 번호는 알아서 뗀다.

```
학성초
한천초, 백곡초
1. 충북외고
충청북도진천교육지원청 학성초등학교
```

### 부서에 보내려면

교육청·교육지원청·직속기관의 **부서**도 수신자가 된다. 다만 학교와 달리 이름 하나로는
안 될 때가 있다.

| 입력 | 결과 |
|---|---|
| `정책기획과` | 한 곳뿐이라 바로 확정 |
| `행정과` | **11곳에 있어 확정하지 않는다.** 후보를 보여주고 고르게 한다 |
| `청주교육지원청 행정과` | 상위조직과 맞물려 한 곳으로 좁혀진다 |
| `단재교육연수원 교육연수부` | 3단계도 된다 |
| `충청북도청주교육지원청 행정과` | 전체경로 그대로도 된다 |

전체경로를 외울 필요는 없다. `기관 찾아보기…` 버튼을 누르면 770곳을 검색해서 고를 수 있다.
찾을 말을 띄어쓰기로 나눠 적으면 모두 포함된 것만 걸러진다 — `청주 초등학교`, `행정과`,
`단재 연수부` 처럼.

부서는 **엑셀 경로를 쓰는 편이 안전하다.** 좌표 자동선택은 조직명 칸에 `행정과` 를 쳐서
첫 결과를 고르는 방식이라, 여러 곳에 겹치는 부서명에서는 엉뚱한 곳이 잡힐 수 있다.

### 결과 확인

`명단 추출 →` 를 누르면 네 갈래로 나뉜다.

- **확정** — 정식명·별칭·전체경로가 정확히 맞은 것
- **같은 이름이 여럿** — `행정과` 처럼 실재하는 기관이 여러 곳인 것. 더블클릭해서 고른다
- **추정** — 편집거리로 짐작만 된 것. 역시 더블클릭해서 고른다
- **찾지 못함** — 사전에 없는 것

**추정 상태로는 엑셀에 실리지 않는다.** 엑셀은 그대로 등록되므로, 틀린 기관이 조용히
들어가는 것을 막는 가장 중요한 규칙이다.

`4. 수신그룹 엑셀` 탭에서 그룹명을 적고 `수신그룹 엑셀 만들기`.
코드가 없는 기관은 목록으로 알려준다 — 조용히 빠지지 않는다.

### 4. 코드가 없는 기관은

`클립보드 순차 복사` 를 쓴다. 기관명을 한 건씩 클립보드에 넣어 주므로,
조직명 칸에 `Ctrl+V` → Enter → 체크 → `>>` 만 반복하면 된다. Enter 키로 다음으로 넘어간다.

수신픽에는 위치 설정이 없다. 엑셀을 만들어 올리는 방식이라 좌표를 잡을 일이 없다.
소통픽에서 잡아 둔 좌표는 그대로 남는다.

## 안전장치

공문이 엉뚱한 기관으로 가는 것을 막는 규칙들이다.

- **추정은 자동 확정하지 않는다.** 정확 일치·약칭·접두어까지만 자동이고, 편집거리 추정은
  사람이 골라야 한다.
- **동명 기관은 추측하지 않는다.** `행정과` 는 11곳에 있다. 짧은 이름으로 후보가 둘 이상이면
  아무것도 고르지 않고 후보를 보여준다. 전체경로(`충청북도충주교육지원청 행정과`)로는 정확히 찾는다.
- **비슷한 지역명을 편집거리로 붙이지 않는다.** 청주와 충주는 한 글자 차이다. 해석 경로에서
  퍼지 매칭을 모두 뺐다 — `청주교육지원청 행정과` 가 충주로 가면 안 되기 때문이다.
- **빠지는 것은 반드시 알린다.** 코드 없음·이름 미확정은 사유와 함께 목록으로 나온다.
- **학교급을 넘지 않는다.** `오송솔미초` 가 `오송솔미초병설유치원` 으로 붙지 않는다.

### 갱신

학교 신설·통폐합이 있으면:

```bash
python3 tools/merge_neis.py            # 미리보기
python3 tools/merge_neis.py --apply    # 나이스 CSV로 org_db 보강

python3 tools/merge_edufine_orgs.py --apply   # 수확한 기관명을 org_db 에 반영
```

둘 다 **기존 별칭을 덮어쓰지 않고 추가만 한다.** 반복 실행해도 안전하다.

기관코드는 앱의 `기관코드 가져오기` 로 갱신한다. 코드가 바뀐 기관이 있으면
무엇이 어떻게 바뀌는지 먼저 보여주고 확인을 받는다.

## 개발

```bash
pip install -r requirements.txt
python3 -m unittest discover -s tests    # 87개
python main.py
```

빌드는 `build.bat` (PyInstaller, 산출물 `dist/sintongpick.exe`).
CI 는 onefile exe 와 onedir zip 을 모두 만들고, `tools/make_version_file.py` 로
제품명·회사명·버전을 exe 에 박는다 (비어 있으면 백신 의심 점수가 올라간다).

### 릴리즈

방법은 두 가지다. 어느 쪽이든 GitHub Actions 가 Windows 러너에서 exe 를 만들어
Release 에 붙인다.

**태그를 민다**

```bash
git tag -a v2.0.1 -m "무엇을 고쳤는지"
git push origin v2.0.1
```

**또는 Actions 탭에서 돌린다**

`Actions → 릴리즈 빌드 → Run workflow` 에서 `version` 에 `v2.0.1` 을 적는다.
러너가 태그까지 만들어 주므로 **태그를 밀 권한이 없어도 된다.**
`version` 을 비워 두면 빌드만 하고 exe 를 artifact 로만 남긴다.

워크플로는 `.github/workflows/release.yml` 이고 세 가지를 순서대로 한다.

1. **테스트** (ubuntu) — GUI 없이 도는 부분 전부
2. **스모크 테스트** (windows) — `tools/smoke_gui.py` 로 탭 생성·도구 전환·명단 추출까지
   실제로 돌려 본다. exe 를 만들기 전에 여기서 걸러야 사용자가 받고 나서 아는 일이 없다.
   대화상자는 전부 실패로 처리한다 — CI 에는 누를 사람이 없어 모달이 뜨면 영영 멈춘다.
3. **빌드 + Release 첨부**

빌드만 확인하고 싶으면 `version` 을 비워 두고 돌린다. Release 없이 exe 만 남는다.

### 랜딩페이지 배포 (Vercel)

`index.html` 한 장이 전부다. 인라인 CSS 와 외부 링크만 쓰므로 다른 파일이 필요 없다.

**Git 연동 (권장)** — [vercel.com/new](https://vercel.com/new) 에서 이 저장소를 고르고
Framework Preset 을 `Other`, Build Command 를 비워 두면 끝난다. 이후 `main` 에 푸시할
때마다 자동 배포된다. 토큰이나 시크릿을 넣을 일이 없다.

**CLI**

```bash
npm i -g vercel
vercel          # 미리보기
vercel --prod   # 운영 배포
```

`.vercelignore` 가 `index.html` 과 `vercel.json` 만 남기고 전부 제외한다.
빼지 않으면 `outputDirectory` 가 저장소 루트라 앱 소스와 `data/` 의 4MB CSV 까지
공개 URL 로 서빙된다.

`vercel.json` 에 짧은 주소를 두 개 걸어 뒀다.

| 주소 | 가는 곳 |
|---|---|
| `/download` | 최신 릴리즈 |
| `/github` | 저장소 |

배포 후 랜딩페이지 주소를 동료에게 알려주면 거기서 바로 받을 수 있다.

GUI 없이도 핵심 로직은 전부 테스트된다 — 파싱, 매칭 등급, 코드 조회, 엑셀 생성,
그리고 붙여넣기부터 엑셀까지 전체 경로.
