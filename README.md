# 신통픽

**수**신 + 소**통**. 충북 교사가 수신자를 고르는 두 가지 일을 한 앱에서 한다.

명단을 붙여넣으면 충북 기관명으로 정리하는 파이프라인은 하나이고, 그 결과를 내보내는
출구가 둘이다.

| 출구 | 하는 일 |
|---|---|
| **소통메신저** | [사용자 선택] 창에서 검색 → 결과 클릭 → 선택을 자동 반복 |
| **에듀파인** | [수신자 지정] 팝업 자동 선택, 또는 개인수신그룹 일괄등록 엑셀 생성 |

Windows 전용 · 무설치 · [소통픽](https://github.com/codersongpro/sotong)의 후속.

---

## 에듀파인 수신그룹이 왜 필요한가

공문 기안에서 수신 기관이 30곳이면 조직도에서 검색 → 체크 → `>>` 를 30번 반복해야 한다.
클릭 120번이다. 동명 기관을 잘못 고르면 공문이 엉뚱한 곳으로 간다.

에듀파인에는 `개인설정 > 개인수신그룹관리 > 일괄등록` 이 있다. 엑셀 한 장을 올리면
수신그룹이 통째로 만들어지고, **다음부터는 `수신자 지정 > 개인수신그룹` 에서 그룹 하나만
고르면 끝난다.** 클릭 120번이 2번이 된다.

신통픽은 그 엑셀을 만들어 준다.

## 쓰는 순서

### 1. 기관코드 가져오기 (처음 한 번)

일괄등록 양식의 `수신기관코드` 는 행정표준코드도 나이스 학교코드도 아닌 **에듀파인 내부
코드**다 (영문자 1 + 숫자 9, 충북은 `M10`으로 시작). 공개 데이터로는 구할 수 없어서
에듀파인에서 직접 가져온다.

1. `개인설정 > 개인수신그룹관리` 에서 그룹을 하나 만들고, 조직도에서 기관을 선택해 저장
2. 같은 화면의 `파일양식받기` — 방금 등록한 내용이 **코드와 함께** 내려온다
3. 신통픽 `4. 수신그룹 엑셀` 탭 → `기관코드 가져오기…` 에서 그 파일 선택

조직도 상위 노드를 통째로 선택하면 한 번에 수백 곳을 가져올 수 있다.
저장소에는 이미 충북 **770곳**이 들어 있다 (`org_codes.json`).

### 2. 내 정보 (처음 한 번)

`등록교육청코드` · `사용자ID` · `사용자명`. 가져오기 파일에서 자동으로 채워지지만,
**이미 채워 둔 값은 덮어쓰지 않는다** — 조직도를 통째로 내보낸 파일에는 본인 것이 아닌
등록교육청코드가 들어 있을 수 있기 때문이다.

`등록교육청코드`는 본인이 속한 교육지원청 코드다 (예: 진천 `M100000098`).

### 3. 명단 넣고 엑셀 만들기

`1. 명단 입력` 탭에서 출구를 **에듀파인**으로 두고 기관 명단을 붙여넣는다.
줄바꿈·쉼표·탭 아무거나 되고, 글머리기호와 번호는 알아서 뗀다.

```
학성초
한천초, 백곡초
1. 충북외고
충청북도진천교육지원청 학성초등학교
```

### 부서에 보내려면

교육청·교육지원청·직속기관의 **부서**도 수신자가 된다. 다만 학교와 달리 이름 하나로는
안 될 때가 있다.

| 입력 | 결과 |
|---|---|
| `정책기획과` | 한 곳뿐이라 바로 확정 |
| `행정과` | **11곳에 있어 확정하지 않는다.** 후보를 보여주고 고르게 한다 |
| `청주교육지원청 행정과` | 상위조직과 맞물려 한 곳으로 좁혀진다 |
| `단재교육연수원 교육연수부` | 3단계도 된다 |
| `충청북도청주교육지원청 행정과` | 전체경로 그대로도 된다 |

전체경로를 외울 필요는 없다. `기관 찾아보기…` 버튼을 누르면 770곳을 검색해서 고를 수 있다.
찾을 말을 띄어쓰기로 나눠 적으면 모두 포함된 것만 걸러진다 — `청주 초등학교`, `행정과`,
`단재 연수부` 처럼.

부서는 **엑셀 경로를 쓰는 편이 안전하다.** 좌표 자동선택은 조직명 칸에 `행정과` 를 쳐서
첫 결과를 고르는 방식이라, 여러 곳에 겹치는 부서명에서는 엉뚱한 곳이 잡힐 수 있다.

### 결과 확인

`명단 추출 →` 를 누르면 네 갈래로 나뉜다.

- **확정** — 정식명·별칭·전체경로가 정확히 맞은 것
- **같은 이름이 여럿** — `행정과` 처럼 실재하는 기관이 여러 곳인 것. 더블클릭해서 고른다
- **추정** — 편집거리로 짐작만 된 것. 역시 더블클릭해서 고른다
- **찾지 못함** — 사전에 없는 것

**추정 상태로는 엑셀에 실리지 않는다.** 엑셀은 그대로 등록되므로, 틀린 기관이 조용히
들어가는 것을 막는 가장 중요한 규칙이다.

`4. 수신그룹 엑셀` 탭에서 그룹명을 적고 `수신그룹 엑셀 만들기`.
코드가 없는 기관은 목록으로 알려준다 — 조용히 빠지지 않는다.

### 4. 코드가 없는 기관은

`클립보드 순차 복사` 를 쓴다. 기관명을 한 건씩 클립보드에 넣어 주므로,
조직명 칸에 `Ctrl+V` → Enter → 체크 → `>>` 만 반복하면 된다. Enter 키로 다음으로 넘어간다.

또는 출구를 에듀파인으로 둔 채 `2. 위치 설정` 에서 좌표를 잡고 `3. 자동 선택` 을 쓴다.
**좌표는 출구별로 따로 저장되니 소통메신저 설정이 지워지지 않는다.**

## 안전장치

공문이 엉뚱한 기관으로 가는 것을 막는 규칙들이다.

- **추정은 자동 확정하지 않는다.** 정확 일치·약칭·접두어까지만 자동이고, 편집거리 추정은
  사람이 골라야 한다.
- **동명 기관은 추측하지 않는다.** `행정과` 는 11곳에 있다. 짧은 이름으로 후보가 둘 이상이면
  아무것도 고르지 않고 후보를 보여준다. 전체경로(`충청북도충주교육지원청 행정과`)로는 정확히 찾는다.
- **비슷한 지역명을 편집거리로 붙이지 않는다.** 청주와 충주는 한 글자 차이다. 해석 경로에서
  퍼지 매칭을 모두 뺐다 — `청주교육지원청 행정과` 가 충주로 가면 안 되기 때문이다.
- **빠지는 것은 반드시 알린다.** 코드 없음·이름 미확정은 사유와 함께 목록으로 나온다.
- **학교급을 넘지 않는다.** `오송솔미초` 가 `오송솔미초병설유치원` 으로 붙지 않는다.

### 갱신

학교 신설·통폐합이 있으면:

```bash
python3 tools/merge_neis.py            # 미리보기
python3 tools/merge_neis.py --apply    # 나이스 CSV로 org_db 보강

python3 tools/merge_edufine_orgs.py --apply   # 수확한 기관명을 org_db 에 반영
```

둘 다 **기존 별칭을 덮어쓰지 않고 추가만 한다.** 반복 실행해도 안전하다.

기관코드는 앱의 `기관코드 가져오기` 로 갱신한다. 코드가 바뀐 기관이 있으면
무엇이 어떻게 바뀌는지 먼저 보여주고 확인을 받는다.

## 개발

```bash
pip install -r requirements.txt
python3 -m unittest discover -s tests    # 63개
python main.py
```

빌드는 `build.bat` (PyInstaller, 산출물 `dist/sintongpick.exe`).

### 릴리즈

`v` 로 시작하는 태그를 밀면 GitHub Actions 가 Windows 러너에서 exe 를 만들어
Release 에 붙인다.

```bash
git tag -a v2.0.1 -m "무엇을 고쳤는지"
git push origin v2.0.1
```

워크플로는 `.github/workflows/release.yml` 이고 세 가지를 순서대로 한다.

1. **테스트** (ubuntu) — GUI 없이 도는 부분 전부
2. **스모크 테스트** (windows) — `tools/smoke_gui.py` 로 탭 생성·출구 전환·명단 추출까지
   실제로 돌려 본다. exe 를 만들기 전에 여기서 걸러야 사용자가 받고 나서 아는 일이 없다.
   대화상자는 전부 실패로 처리한다 — CI 에는 누를 사람이 없어 모달이 뜨면 영영 멈춘다.
3. **빌드 + Release 첨부**

Actions 탭에서 `Run workflow` 로 손수 돌릴 수도 있다. 이때는 Release 를 만들지 않고
exe 를 artifact 로만 남기므로, 태그를 붙이기 전에 빌드가 되는지 확인할 때 쓴다.

GUI 없이도 핵심 로직은 전부 테스트된다 — 파싱, 매칭 등급, 코드 조회, 엑셀 생성,
그리고 붙여넣기부터 엑셀까지 전체 경로.
