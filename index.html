주요 기능
반복 작업, 이제 맡기세요

수십·수백 명의 수신자를 일일이 검색하고 클릭하는 작업을 자동으로 처리합니다.

📊
엑셀 파일
.xlsx 파일에서 소속기관과 이름을 자동으로 읽어옵니다.
📄
한글 HWP
.hwp · .hwpx 파일도 직접 열어 명단을 추출합니다.
📋
복사·붙여넣기
Ctrl+C로 복사한 표를 바로 붙여넣기 해도 됩니다.
🏛️
에듀파인 수신그룹
기관 명단을 개인수신그룹 일괄등록 엑셀로 만들어 줍니다. 한 번 등록하면 다음부터는 그룹만 고르면 됩니다.
🔢
기관코드 자동 연결
충북 교육기관 770곳의 코드를 알고 있습니다. 확실하지 않은 기관은 추측하지 않고 먼저 물어봅니다.
🔍
오타 자동 보정
최신 충북 학교·기관 DB를 기준으로 기관명 오타를 자동 매칭합니다.
사용 방법
명단은 하나, 출구는 둘

명단을 붙여넣으면 충북 기관명으로 정리합니다. 그 다음이 갈립니다 — 소통메신저에서 자동으로 골라 담거나, 에듀파인 수신그룹 엑셀로 만들거나. 출구는 [1. 명단 입력] 탭 맨 위에서 고릅니다.

▶  영상으로 사용 방법 보기 (YouTube)
  • 1
    소통메신저 발송 창 열기
    오른쪽 위 편지 아이콘(✉) → 쪽지 작성 또는 대화하기 → [사용자 선택] → 전체조직 탭 클릭
  • 2
    명단 입력 — 두 가지 방법 중 선택
    방법 ① 복사·붙여넣기 — 엑셀에서 소속기관(A열)·이름(B열) 선택 후 Ctrl+C, 입력창에 Ctrl+V
    방법 ② 파일 직접 열기 — [엑셀 파일 열기] 또는 [HWP 파일 열기] 버튼 클릭
    A열 — 소속기관B열 — 이름
    충주중학교홍길동
    청주고등학교김철수
    충청북도교육청이영희
  • 3
    [명단 추출 →] 클릭
    소속기관과 이름이 자동 인식되어 목록에 표시됩니다. 목록을 더블클릭하면 항목을 직접 수정할 수 있습니다.
ℹ
최초 1회만 설정하면 됩니다. 소통메신저 창 위치가 바뀌지 않는 한 재설정 불필요합니다. 자동 선택은 검색 → 결과 클릭 → 선택 버튼 클릭의 3단계로 동작합니다.
  • 1
    STEP 1 — 검색 입력창 위치
    [📍 위치 설정] → [캡처 시작] 클릭 → 소통메신저 검색 입력칸 위로 마우스 이동 → Enter로 확정
  • 2
    STEP 2 — 결과 첫 번째 항목 위치
    임의 이름 검색 후 결과 목록의 첫 번째 줄이 보이는 상태에서 [📍 위치 설정] → [캡처 시작] → 첫 번째 줄 위로 마우스 이동 → Enter로 확정
  • 3
    STEP 3 — 사용자 선택 버튼 위치
    결과 목록이 보이는 상태에서 [📍 위치 설정] → [캡처 시작] → [사용자 선택] 또는 [추가] 버튼 위로 마우스 이동 → Enter로 확정
  • 4
    [✅ 설정 저장] 클릭
    반드시 저장해야 다음 실행 시에도 설정이 유지됩니다.
  • 1
    [▶ 자동 선택 시작] 클릭
    소통메신저 사용자 선택 창이 열려있는 상태에서 시작하세요.
  • 2
    자동 진행 — 마우스를 움직이지 마세요
    이름마다 ① 검색 입력 → ② 결과 첫 번째 클릭 → ③ 선택 버튼 클릭 이 자동으로 반복됩니다. 진행 상황이 로그에 실시간 표시됩니다.
  • 3
    완료 — 결과 확인
    ✓ 성공 / ✗ 실패 건수가 요약됩니다. 빨간색 항목은 검색 결과가 없는 경우입니다.
⚠
긴급 중지: 마우스를 화면 왼쪽 위 모서리(0, 0)로 빠르게 이동하거나 [■ 중지] 버튼을 클릭하세요.
ℹ
수신 기관이 30곳이면 조직도에서 검색 → 체크 → [>>] 를 30번 반복해야 합니다. 클릭 120번입니다. 수신그룹을 한 번 등록해 두면 다음부터는 [수신자 지정 > 개인수신그룹] 에서 그룹만 고르면 됩니다 — 클릭 2번이 됩니다.
  • 1
    내 정보 넣기 — 처음 한 번만
    [4. 수신그룹 엑셀] 탭에서 등록교육청을 목록에서 고르고, 에듀파인 사용자ID와 이름을 적습니다. 한 번 넣으면 저장됩니다.
  • 2
    기관 명단 넣기
    줄바꿈·쉼표·탭 아무거나 됩니다. 글머리기호와 번호는 알아서 뗍니다. 학교는 약칭으로 써도 되고, 부서는 [기관 찾아보기…] 로 골라도 됩니다.
    붙여넣는 그대로인식 결과
    학성초학성초등학교
    충북외고충북외국어고등학교
    청주교육지원청 행정과충청북도청주교육지원청 행정과
  • 3
    확인이 필요한 것만 고르기
    행정과 는 11곳에 있습니다. 이런 항목은 확정하지 않고 후보를 보여줍니다. 더블클릭해서 고르세요. 추정 상태로는 엑셀에 실리지 않습니다 — 엑셀은 그대로 등록되므로 틀린 기관이 조용히 들어가지 않게 막습니다.
  • 4
    엑셀 만들어 올리기
    그룹명을 적고 [수신그룹 엑셀 만들기]. 만들어진 파일을 에듀파인 [개인설정 > 개인수신그룹관리 > 일괄등록] 에 올립니다. 코드가 없는 기관은 목록으로 알려줍니다 — 조용히 빠지지 않습니다.
⚠
처음에는 기관 2~3곳짜리 시험 그룹으로 한 번 올려 보고, 등록된 기관이 의도한 곳과 맞는지 확인한 뒤 실전에 쓰세요.
FAQ
자주 묻는 질문
다운로드 후 실행이 안 돼요. Windows 경고가 뜹니다.
추가 정보를 클릭한 뒤 실행을 선택하세요. 소규모 배포 프로그램은 코드 서명 인증서가 없어 SmartScreen 경고가 표시될 수 있습니다. 소스 코드는 GitHub에서 누구나 확인할 수 있습니다.
소속기관이 '소속없음'으로 표시돼요.
DB에 없는 기관명이거나 오타가 심한 경우입니다. 추출된 목록에서 해당 항목을 더블클릭하면 직접 수정할 수 있습니다.
프로그램이 엉뚱한 위치를 클릭해요.
소통메신저 창 위치가 바뀌었을 수 있습니다. [2. 위치 설정] 탭에서 위치를 다시 설정하고 저장하세요.
동명이인이 있을 때는 어떻게 하나요?
[2. 위치 설정] 탭에서 수동 확인 모드를 체크하세요. 각 이름 검색 후 소통메신저에서 결과를 직접 클릭하고 선택 버튼을 누른 뒤 [▶▶ 계속] 버튼을 눌러 진행합니다.
HWP 파일이 열리지 않아요.
한/글이 설치되지 않은 경우 일부 형식이 지원되지 않을 수 있습니다. 한글 문서에서 표를 Ctrl+C로 복사한 뒤 입력창에 붙여넣으세요.
에듀파인 기관코드를 따로 구해야 하나요?
아니요. 충북 교육기관 770곳의 코드가 이미 들어 있습니다. 학교 신설·통폐합으로 갱신이 필요할 때만, 에듀파인에서 수신그룹을 하나 저장한 뒤 [파일양식받기] 로 받은 파일을 [기관코드 가져오기…] 에 넣으면 됩니다.
교육청·교육지원청의 부서에도 보낼 수 있나요?
됩니다. 다만 행정과 는 11곳에 있어서 이름만으로는 정해지지 않습니다. 청주교육지원청 행정과 처럼 상위조직을 함께 적으면 한 곳으로 좁혀지고, 그냥 행정과 라고만 적으면 후보를 보여주고 고르게 합니다. 전체경로를 외울 필요는 없습니다 — [기관 찾아보기…] 로 검색해서 고르세요.
엉뚱한 기관이 등록될까 걱정됩니다.
그래서 추정은 자동으로 확정하지 않습니다. 정확히 맞은 것만 엑셀에 실리고, 짐작만 된 것과 같은 이름이 여럿인 것은 사람이 골라야 넘어갑니다. 코드가 없어서 빠지는 기관도 사유와 함께 알려 줍니다. 청주와 충주처럼 한 글자 차이인 지역명을 편집거리로 갖다 붙이지 않도록 해석 경로에서 추정을 모두 뺐습니다.
소통메신저 위치 설정이 지워지나요?
아니요. 클릭 위치는 출구별로 따로 저장됩니다. 에듀파인 쪽 좌표를 새로 잡아도 소통메신저 설정은 그대로 남습니다. 이전 버전(소통픽)에서 쓰던 좌표도 그대로 이어받습니다.
속도를 조절할 수 있나요?
[2. 위치 설정] 탭의 검색 후 대기 시간에서 조절하세요. 기본값은 0.5초이며, 인터넷이 느린 환경에서는 1.5~2초로 늘려보세요.
