# 안내 그림

소통메신저에서 누르는 자리를 캡처한 그림을 여기에 둔다.
앱이 [2. 위치 설정] 탭과 위치 캡처 창에서 함께 보여 준다.
파일이 없으면 글 안내만 나오므로, 없어도 앱은 정상 동작한다.

| 파일 | 무엇을 찍은 그림인가 |
|---|---|
| `step1_write.png` | [쪽지작성] 버튼 |
| `step2_add.png` | [받는사람 추가] 버튼 |
| `step3_search.png` | 검색 입력칸 ('소속+이름 또는 이름 검색') |
| `step4_result.png` | 검색 결과 첫 줄 ('검색 결과(1명)' 아래 첫 사람) |
| `step5_arrow.png` | 오른쪽 화살표 버튼 |

tkinter 가 읽을 수 있게 **PNG** 로 저장한다.
가로 320px 을 넘지 않는 것이 보기 좋다. 개인정보가 보이지 않게 이름과 소속은
가리거나 예시 계정으로 찍는다.
