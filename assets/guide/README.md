# 안내 그림

소통메신저에서 누르는 자리를 캡처한 그림을 여기에 둔다.
앱이 [2. 위치 설정] 탭의 차례 안내와 위치 캡처 창에서 함께 보여 준다.
파일이 없으면 글 안내만 나오므로, 없어도 앱은 정상 동작한다.

| 차례 | 파일 | 무엇을 찍은 그림인가 |
|---|---|---|
| 1 | `mail_button.png` | 오른쪽 위 편지 버튼 (마우스를 올리면 메뉴가 펼쳐진다) |
| 2 | `write_note.png` | 펼쳐진 메뉴의 [쪽지작성] |
| 3 | `add_recipient.png` | [받는사람 추가] 버튼 |
| 4 | `search_box.png` | 검색 입력칸 ('소속+이름 또는 이름 검색') |
| 5 | `first_result.png` | 검색 결과 첫 줄 ('검색 결과(1명)' 아래 첫 사람) |
| 6 | `arrow_button.png` | 오른쪽 화살표 버튼 |

4·5·6 번이 신통픽에 알려 주는 세 자리다. 차례가 바뀌어도 파일 이름은 그대로
쓰도록 뜻으로 지었다. 이름을 바꾸면 `main.GUIDE_IMAGES` 도 함께 고친다.

tkinter 가 읽을 수 있게 **PNG** 로 저장한다.
가로 320px 을 넘지 않는 것이 보기 좋다. 개인정보가 보이지 않게 이름과 소속은
가리거나 예시 계정으로 찍는다.
