# 안내 그림

소통메신저와 에듀파인에서 누르는 자리를 캡처한 그림을 여기에 둔다.
앱이 해당 탭의 차례 안내와 위치 캡처 창에서 함께 보여 주고,
`tools/embed_guide_images.py` 가 같은 파일을 랜딩페이지에도 박아 넣는다.
파일이 없으면 글 안내만 나오므로, 없어도 앱은 정상 동작한다.

## 소통픽 — 소통메신저

앱의 [2. 위치 설정] 탭에 나온다.

| 차례 | 파일 | 무엇을 찍은 그림인가 |
|---|---|---|
| 1 | `mail_button.png` | 오른쪽 위 편지 버튼 (마우스를 올리면 메뉴가 펼쳐진다) |
| 2 | `write_note.png` | 펼쳐진 메뉴의 [쪽지작성] |
| 3 | `add_recipient.png` | [받는사람 추가] 버튼 |
| 4 | `search_box.png` | 검색 입력칸 ('소속+이름 또는 이름 검색') |
| 5 | `first_result.png` | 검색 결과 첫 줄 ('검색 결과(1명)' 아래 첫 사람) |
| 6 | `arrow_button.png` | 오른쪽 화살표 버튼 |

4·5·6 번이 신통픽에 알려 주는 세 자리다. 차례가 바뀌어도 파일 이름은 그대로
쓰도록 뜻으로 지었다. 이름을 바꾸면 `main.GUIDE_IMAGES` 도 함께 고친다.

## 수신픽 — 에듀파인

앱의 [2. 수신그룹 엑셀] 탭 STEP 3 에 나온다. 만든 엑셀을 올릴 때 누르는 차례다.

| 차례 | 파일 | 무엇을 찍은 그림인가 |
|---|---|---|
| 1 | `edufine_settings.png` | 오른쪽 위 [개인설정] |
| 2 | `edufine_group_menu.png` | 왼쪽 메뉴의 [개인수신그룹관리] |
| 3 | `edufine_bulk_upload.png` | 수신그룹 목록 위의 [일괄등록] |
| 4 | `edufine_browse.png` | 파일을 고르는 [찾아보기 ...] |

차례 번호가 소통메신저와 겹치므로 `main.EDUFINE_GUIDE_IMAGES` 로 따로 둔다.
이름을 바꾸면 그쪽도 함께 고친다.

## 파일 규칙

tkinter 가 읽을 수 있게 **PNG** 로 저장한다.
가로 320px 을 넘지 않는 것이 보기 좋다. 개인정보가 보이지 않게 이름과 소속은
가리거나 예시 계정으로 찍는다.

그림을 새로 찍거나 바꾼 뒤에는 랜딩페이지에도 반영한다.

```bash
python3 tools/embed_guide_images.py
```

`index.html` 에 박아 둔 그림이 이 폴더의 파일과 다르면 테스트가 잡는다.
